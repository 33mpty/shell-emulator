# shell-emulator

Эмулятор командной оболочки UNIX-подобной ОС, работающий поверх
виртуальной файловой системы (VFS). Практическая работа №1 по дисциплине
«Конфигурационное управление», вариант 3.

Выполненные этапы: 1 (REPL), 2 (конфигурация).

## Общее описание

Приложение реализовано как консольный интерфейс (CLI). Пользователь
вводит команды в приглашение вида `minimal> `, эмулятор разбирает ввод,
находит команду и выполняет её. Команды можно подать не только вручную,
но и стартовым скриптом.

## Параметры командной строки

| Параметр | Назначение |
|---|---|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--script PATH` | путь к стартовому скрипту эмулятора |
| `--help` | справка по параметрам |

Оба параметра необязательны. При запуске эмулятор печатает отладочный
вывод всех заданных параметров (строки с префиксом `[debug]`).

Имя VFS берётся из имени файла, указанного в `--vfs`, и попадает в
приглашение к вводу: для `vfs/minimal.xml` приглашение будет
`minimal> `. Без параметра используется имя `vfs`.

## Команды эмулятора

| Команда | Состояние |
|---|---|
| `ls [аргументы]` | заглушка: печатает имя и аргументы |
| `cd <путь>` | заглушка: печатает имя и аргумент |
| `exit` | завершает работу эмулятора |

Логика `ls` и `cd` реализуется на этапе 4, работа с VFS — на этапе 3.

Обработка ошибок: неизвестная команда и неверное число аргументов
выводят сообщение, выполнение продолжается.

## Стартовый скрипт

Текстовый файл, одна команда в строке. Выполняется последовательно,
ошибочные строки пропускаются. На экране отображается и ввод, и вывод,
имитируя диалог с пользователем. Пустые строки и строки, начинающиеся
с `#`, игнорируются. Команда `exit` в скрипте завершает работу, не
открывая интерактивный режим.

Если файл скрипта не найден, выводится сообщение об ошибке, после чего
эмулятор переходит в интерактивный режим.

Готовые скрипты:

| Файл | Содержимое |
|---|---|
| `startup/basic.txt` | обычные команды |
| `startup/errors.txt` | строки с ошибками, которые пропускаются |
| `startup/with_exit.txt` | завершение работы через `exit` |

## Структура проекта

| Путь | Назначение |
|---|---|
| `src/emulator/config.py` | разбор параметров и отладочный вывод |
| `src/emulator/parser.py` | разбор строки на команду и аргументы |
| `src/emulator/commands.py` | команды и словарь `COMMANDS` |
| `src/emulator/script_runner.py` | выполнение стартового скрипта |
| `src/emulator/shell.py` | класс `Shell`, цикл REPL |
| `src/emulator/__main__.py` | точка входа |
| `tests/` | тесты |
| `startup/` | стартовые скрипты эмулятора |
| `scripts/` | скрипты реальной ОС для тестирования параметров |
| `vfs/` | файлы VFS |

## Сборка и запуск

Требуется Python 3.9 или новее. Внешних зависимостей нет, для тестов
нужен `pytest`.

```sh
./run.sh                                   # интерактивный режим
./run.sh --vfs vfs/minimal.xml             # с указанием VFS
./run.sh --script startup/basic.txt        # со стартовым скриптом
make run                                   # то же, что ./run.sh
make test                                  # запуск тестов
```

## Запуск в Windows

```bat
run.bat                                    :: интерактивный режим
run.bat --vfs vfs\minimal.xml              :: с указанием VFS
run.bat --script startup\basic.txt         :: со стартовым скриптом
python -m pytest tests                     :: тесты (нужен pytest)
```

Скрипт `run.bat` сам подставляет `PYTHONPATH=src` и вызывает
`python -m emulator`. Скрипты из папки `scripts` написаны для sh и
запускаются в Git Bash, который устанавливается вместе с Git for
Windows.

## Скрипты тестирования параметров

Скрипты реальной ОС, каждый проверяет свою комбинацию параметров:

```sh
scripts/run_no_params.sh      # без параметров
scripts/run_vfs_only.sh       # только --vfs
scripts/run_script_only.sh    # только --script, скрипт с ошибками
scripts/run_all_params.sh     # оба параметра
scripts/run_bad_script.sh     # несуществующий скрипт
scripts/run_exit_script.sh    # скрипт с командой exit
```

## Примеры использования

Запуск со всеми параметрами:

```
$ ./run.sh --vfs vfs/minimal.xml --script startup/basic.txt
[debug] параметры запуска:
[debug]   vfs    = vfs/minimal.xml
[debug]   script = startup/basic.txt
[debug]   имя VFS в приглашении = minimal
minimal> ls
ls
minimal> ls -l /home
ls -l /home
minimal> cd /home
cd /home
```

Пропуск ошибочных строк скрипта:

```
$ ./run.sh --script startup/errors.txt
vfs> ls /home
ls /home
vfs> privet
privet: команда не найдена
vfs> cd a b
cd: ожидается один аргумент
vfs> ls -a
ls -a
```

Интерактивный режим:

```
$ ./run.sh
vfs> cd docs
cd docs
vfs> hello
hello: команда не найдена
vfs> exit
```
