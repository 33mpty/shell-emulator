# shell-emulator

Эмулятор командной оболочки UNIX-подобной ОС, работающий поверх
виртуальной файловой системы (VFS). Практическая работа №1 по дисциплине
«Конфигурационное управление», вариант 3.

## Описание

Приложение реализовано как консольный интерфейс (CLI). Пользователь
вводит команды в приглашение вида `vfs> `, эмулятор разбирает ввод и
выполняет команду.

## Функции

- `src/emulator/parser.py` — `parse_line(line)`: разделяет строку по
  пробелам на команду и список аргументов.
- `src/emulator/commands.py` — реализации команд и словарь `COMMANDS`.
  - `ls` — заглушка, печатает имя команды и аргументы.
  - `cd` — заглушка, принимает ровно один аргумент.
- `src/emulator/shell.py` — класс `Shell`: приглашение, выполнение
  одной строки, интерактивный цикл.
- `exit` — завершает работу эмулятора.

При неизвестной команде или неверных аргументах выводится сообщение об
ошибке, работа продолжается.

## Сборка и запуск

Требуется Python 3.9+. Внешних зависимостей нет (для тестов — `pytest`).

```sh
./run.sh        # запуск эмулятора
make run        # то же самое
make test       # запуск тестов
```

## Пример использования

```
vfs> ls -l /home
ls -l /home
vfs> cd docs
cd docs
vfs> cd a b
cd: ожидается один аргумент
vfs> hello
hello: команда не найдена
vfs> exit
```
